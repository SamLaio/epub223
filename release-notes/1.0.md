# epub223 1.0

## 變更內容

- 新增 `python -m epub3itizer --version`，讓工具可直接回報版本。
- 修復舊 EPUB 內 XHTML/OPF 非 UTF-8 編碼時的讀取問題，支援 XML encoding 宣告與 `cp950`、`big5`、`gb18030` fallback。
- 補強 OPF metadata 清理，移除 EPUB3 不允許的私有 `<meta>` 屬性與缺少 `content` 的無效 meta。
- 補強 nav 清理，移除空的 `span`、`a`、`div`，並將 nav 裡的 `ul` / `menu` 轉為 EPUB3 合法的 `ol`。
- 補強 manifest 與固定版面清理，移除 stale `scripted` property 與不適用的全域固定版面宣告。

## 驗證方式

- `python -m pytest -q`
- `python -m epub3itizer --version`
