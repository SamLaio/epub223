# ePub223 1.2

## 變更內容

- OPF 清理新增 `<package xml:lang>` 正規化，避免不合法語言碼造成 EPUBCheck `OPF-092`。
- OPF manifest 清理會移除指向不存在 manifest id 的 `fallback` 屬性，避免 EPUBCheck `OPF-040`。
- XHTML 清理新增重複 charset meta 合併，只保留單一 UTF-8 宣告。
- 前置檔名空白修復與路徑大小寫修復遇到不可讀的舊 NCX 或文字檔時會跳過內容改寫，改由後續 manifest/NCX 清理接手，避免亂碼檔中止修復流程。

## 相容性

- CLI 使用方式不變。
- 這版只擴充安全修復規則，不改變 `epubCheck` 作為外部驗證工具的定位。

## 驗證

- `python -m pytest -q`
